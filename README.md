# llvm-pass-lens

Fine-tunes a 120B LLM to classify how pairs of LLVM optimization passes
interact, using ground truth derived from real `opt` runs rather than
hand-labeled or heuristic data.

## Status

Data collection and the training/eval pipeline are implemented. The
fine-tuning run itself has not been executed yet, so no accuracy result
is reported here. This section will be updated with real numbers only
after `trainfixed.py` is run end-to-end and produces
`baseline_raw_outputs.jsonl` and `fine-tuned_raw_outputs.jsonl` —
per-example raw model output kept alongside the aggregate accuracy so
any reported number can be spot-checked rather than taken on faith.

## What it does

Given two LLVM passes and an IR snippet, the model classifies their
interaction as:

- `safe` — pass order does not affect the output (`A→B == B→A`)
- `interferes` — pass order changes the output (`A→B != B→A`)

## Dataset

Ground truth is generated by actually running `opt` with each pass
ordering and diffing the resulting IR (`ground_truth_gen.py`), not by
asking a model to guess.

- `compiler_passes.jsonl` — 280 examples generated from 20 IR snippets
  across a fixed set of LLVM passes
- `compiler_passes_clean.jsonl` — 182 examples, after removing rows
  where the same pass-pair carried contradictory labels
- `contradictory_label_rows.jsonl` — the 98 removed rows, kept for
  re-verification rather than discarded
- Class balance in the clean set: `safe: 110, interferes: 72`
- Held-out test split: 39 examples, grouped by IR snippet to prevent
  the same underlying code appearing in both train and test

## Files

| File | Purpose |
|---|---|
| `trainfixed.py` | Training + eval pipeline |
| `ground_truth_gen.py` | Generates labels via real `opt` runs (requires LLVM 18+) |
| `check_dataset.py` | Reports contradictory-label pass-pairs |
| `filter_dataset.py` | Removes contradictory rows, writes the clean dataset |
| `compiler_passes.jsonl` | Full raw dataset |
| `compiler_passes_clean.jsonl` | Deduplicated dataset used for training |
| `contradictory_label_rows.jsonl` | Rows pending re-verification |
| `baseline_raw_outputs.jsonl` / `fine-tuned_raw_outputs.jsonl` | Per-example raw model output, written after a real run |

## Setup

```bash
pip install -r requirements.txt
export TINKER_API_KEY="your_key_here"
python trainfixed.py
```

Regenerating the dataset via `ground_truth_gen.py` additionally
requires an LLVM 18+ `opt` on PATH. Training itself only reads the
pre-generated `compiler_passes_clean.jsonl`.
